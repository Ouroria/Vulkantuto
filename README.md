I. Presentation:
   
  Ce projet est l'apprentissage de la librairie Vulkan en c++ ainsi que la creation d'un cube 3d

II. Prérequis

Les outils et bibliothèques suivants sont nécessaires pour compiler et exécuter le projet :

Le Vulkan SDK version 1.4.357.0, pour les en-têtes, les bibliothèques et les outils de compilation des shaders.

GLFW, pour la création de la fenêtre et la gestion des événements.

GLM, pour les opérations mathématiques utilisées en rendu 3D.

stb_image, pour le chargement des images utilisées comme textures. (stb_image est inclue dans ce projet et utilise "stb_image au lieu de <stb_image>")

Un GPU et un pilote graphique compatibles avec Vulkan.

III. Exécution

   Double click sur "Vulkan.exe" dans VulkanTuto\Vulkan

IV. Version Debug

   Renderer.cpp ligne 177 enlever le commantaire a une ligne
